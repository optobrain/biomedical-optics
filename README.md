# Biomedical Optics

Course materials for ENGN 1225, a Brown Engineering course on using light
to advance biomedical imaging, medical devices, and healthcare.

The course builds optical imaging from first principles through ray optics,
wave optics, and beam optics, with topics including thin lenses, ray transfer
matrix analysis, convolution, depth of field, electromagnetic waves, Fourier
optics, diffraction, widefield microscopy, Gaussian beams, scanning microscopy,
and optical coherence tomography.

The course emphasizes practical optical-system design and scientific computing:
students use Python or MATLAB for symbolic and numerical analysis, visualization,
homework, and computational labs.
